# Reference Implementations

This directory contains the reference implementations for the practical exercises on neural networks and numerical solvers.

These educational materials illustrate selected applications of **Scientific Machine Learning** to **Numerical Analysis** and **Scientific Computing**, including neural network architectures, learning-based numerical solvers, and physics-informed machine learning.

## Organization

- `notebooks/`: executable Jupyter notebooks containing the reference solutions.
- `scripts/`: corresponding standalone Python implementations.
- `docs/`: supporting documentation.

## Practical Exercises

The examples cover four main topics:

1. **Model Architecture** — Multilayer perceptrons (MLPs), convolutional neural networks (CNNs), and graph neural networks (GNNs).
2. **Training Process** — Training neural networks with weakly and strongly enforced physical constraints.
3. **Hybrid Corrector** — Learning error corrections from residuals to improve iterative numerical solvers.
4. **Hybrid Accelerator** — Learning approximate solutions to initialize and accelerate iterative numerical solvers.

## Scientific Background

The examples are based on the scientific concepts and implementations discussed in the following research article:

**How to Learn Physics: A Practical Review of Scientific Machine Learning**

Marien Chenaud, José Alves, Frédéric Magoulès

*Archives of Computational Methods in Engineering*, 33, 13653-13681, 2026.

The original research repository is available at:

https://github.com/marien-chenaud/scientific_ml

This directory provides educational adaptations and reference solutions for practical exercises. It is not the official repository of the article.
